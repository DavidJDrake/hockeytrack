# Query API Implementation Plan

**Goal:** A public read-only JSON API over the archive (schedule, games, plays, boxscores, shifts, standings, season statistics, players, search), served by a fourth `MODE` of the ingestor behind CloudFront, fed by an indexer that derives per-game summaries and season rollups from the raw feeds.

**Spec:** `docs/superpowers/specs/2026-10-11-query-api-design.md`

**Tech:** Go 1.27 standard library (`net/http` mux, `encoding/json`), `aws-lambda-go` events, AWS SDK v2 S3, Terraform (CloudFront, Lambda Function URL with OAC, EventBridge, Scheduler).

## Global constraints

- No new Go module dependencies: the Function URL adapter and the TTL cache are written here.
- Every raw field is untrusted; decode defensively, never panic on a feed.
- Nothing in the poller, schedule-sync, sweeper, backfill, event contract or golden files changes.
- `gofmt`, `go vet`, `go test ./...`, `terraform fmt -check`, `terraform validate` all pass.
- US spelling.

## Tasks

1. **Model and summarizer** — `store.DirArchive`; `lake` types and decoders; `Summarize` with tests on `internal/nhl/testdata` (all four feeds) and `internal/synth/testdata` (pbp only, eight games).
2. **Rollup and index** — `Rollup` with tests on the eight synthetic games; `Indexer` with tests on a `FakeArchive`; `SyncSeason` builds only what is missing.
3. **API core** — `respond`, `cache`, `server` with `/healthz`, `/v1`, `/v1/seasons`, `/v1/games/*`; Function URL adapter; tests.
4. **API breadth** — schedule, teams, standings, stats, players, search; OpenAPI document; tests.
5. **Entry points** — ingestor modes, `cmd/api`, `cmd/index`, Makefile targets.
6. **Infrastructure and docs** — `terraform/api.tf` and the small edits; README; threat model; `terraform validate`.
7. **Verify** — `make test` (vuln + tests), `gofmt -l`, `go vet`, `terraform fmt -check`, `terraform validate`; commit.
